# Security policy

StackArr stores API keys and credentials for indexers, metadata services, and
download clients. Please do not disclose a suspected vulnerability in a public
issue, discussion, pull request, or chat.

## Reporting a vulnerability

Use GitHub's **Security** tab for this repository and select **Report a
vulnerability** to open a private security advisory. Include:

- affected commit or release;
- reproduction steps or a minimal proof of concept;
- expected impact and any known exploitation conditions; and
- a safe way to contact you for follow-up.

The maintainers will acknowledge a complete report within five business days.
We aim to provide an initial severity assessment and next-step plan within ten
business days. Timelines for a fix depend on impact and complexity; reporters
will receive progress updates at least every fourteen days while remediation
is active.

Please allow a coordinated fix and release before publishing details. We will
credit reporters who want attribution.

## Supported versions

StackArr is pre-alpha and has no supported release line yet. Security fixes are
made on the default branch. This section will be replaced with a release support
matrix before the first stable release.
